Nijatva - what is in the bundled filter lists
=============================================

Files in this folder, read by AdFilterEngine:

  easylist_net.txt.gz       133,213 network rules, one per line
  easylist_cosmetic.txt.gz   14,999 element-hiding rules
  ads.txt                        30 ad hosts, written by hand
  trackers.txt                   30 tracker hosts, written by hand

Format the engine understands
-----------------------------
Network rules are host anchors (||example.com^) and plain substrings.
Options after $ are dropped, regular expressions are skipped, @@ marks an
exception. Cosmetic rules are domain##selector or ##selector; selectors using
:has-text, :style(), :upward, :xpath, :remove() or :matches- are skipped
because the engine turns them into plain CSS.

Where the lists come from
-------------------------
The two easylist_* files are derived from the EasyList project
(https://easylist.to, github.com/easylist/easylist), which is published under
Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0). They are bundled
here under the same licence, unmodified in substance: only rules the engine
cannot execute were dropped.

To update them, replace the two .gz files with freshly generated ones in the
same format. Nothing in the code needs to change.

To add your own rules without rebuilding, use Settings - Advanced - URL filters
for network rules, and Advanced - User styles for cosmetic rules.
