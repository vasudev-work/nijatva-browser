How it is built

Small on purpose. The engine is the one already on your phone; everything else is ours.

The engine is the system WebView

Not a bundled Chromium. It means a nine megabyte install, and it means updates arrive with the system rather than with us. The trade is honest: no chrome.* APIs, so extensions are scripts, not add-ons.

Kotlin, no Play Services

Written for AOSP. It runs on a de-Googled Android and on BharOS, where a Play Services dependency would simply fail at launch.

A store you can check

The catalogue is a JSON file with an ECDSA signature and a sha256 per script. Both browsers read the same file from a GitHub page, and refuse it if it does not verify.

Nothing leaves the device

No telemetry, no crash reporting, no remote config. Bookmarks, history and settings are plain files you can read.
